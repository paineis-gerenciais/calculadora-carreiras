# Calculadora de carreiras

Ferramenta para estimar, ano a ano, o impacto financeiro de carreiras de servidores públicos e comparar propostas de mudança com o cenário atual. Resultados em tabelas e gráficos, com exportação para Excel, PowerPoint e JSON.

- **Endereço:** https://paineis-gerenciais.github.io/calculadora-carreiras/
- **Este repositório só publica o site.** O desenvolvimento, a documentação e os testes ficam em [`paineis-gerenciais/projetos-dev`](https://github.com/paineis-gerenciais/projetos-dev), pasta `simulador-carreiras/` (demanda [#9](https://github.com/paineis-gerenciais/projetos-dev/issues/9)).
- **Dados:** Firestore do projeto `calculadora-carreiras` (plano gratuito). Não use dados pessoais: a planilha da base não pode ter nome, CPF ou matrícula. O site não tem login (risco aceito pelo responsável); qualquer pessoa com o endereço pode ver e alterar os estudos. Exporte o JSON de cada estudo como cópia de segurança.
- **Logos:** `logo-esquerda.png` (largura até 270 px) e `logo-direita.png` (até 185 px) ficam na raiz deste repositório. Sem eles, o site mostra o texto alternativo.
- **Estimativa de apoio à decisão;** não é peça oficial. A validação jurídica é do órgão.
